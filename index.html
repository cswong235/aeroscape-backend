Aeroscape API

All request and response bodies are JSON. Send requests with the header Content-Type: application/json.

Routes marked Requires auth need the header Authorization: Bearer <accessToken>. A missing, invalid or expired token returns 401 with an empty body.

Access tokens expire after 15 minutes. Refresh tokens expire after 7 days.

Authentication

POST /signup

Creates a new account.

Body:

{
        "username": "string, 3 to 100 characters",
        "email": "string, valid email",
        "password": "string, at least 8 characters"
        }

Returns 201:

{ "id": 1, "username": "...", "email": "...", "created_at": "..." }

Errors: 400 failed validation, 409 email already registered, 500 server error.

POST /login

Logs in and returns a pair of tokens.

Body:

{ "email": "string", "password": "string" }

Returns 200:

{ "accessToken": "...", "refreshToken": "..." }

Errors: 404 no account with that email, 401 wrong password, 500 server error.

POST /refresh

Exchanges a refresh token for a new access token.

Body:

{ "refreshToken": "string" }

Returns 200:

{ "accessToken": "..." }

Errors: 401 refresh token missing, invalid or expired.

Posts

POST /posts

Requires auth. Creates a post by the logged-in user.

Body:

{
        "title": "string, optional",
        "content": "string, required",
        "visibility": "public | friends_only"
        }

Returns 201:

{
        "message": "Post added successfully",
        "result": { "id": 1, "user_id": 1, "title": "...", "content": "...", "visibility": "...", ... }
        }

Errors: 404 content is missing, 500 server error.

GET /posts

Requires auth. Returns the posts the logged-in user can see:

  • all public posts
  • the user's own posts
  • friends-only posts from authors who have added the user as a friend

Body: none

Returns 200: an array of posts, each with the author's username.

[
        { "id": 1, "user_id": 1, "title": "...", "content": "...", "visibility": "...", "username": "...", ... }
        ]

Errors: 500 server error.

Users

GET /users

Requires auth. Returns every user except the logged-in user.

Body: none

Returns 200:

[
        { "id": 2, "username": "...", "email": "...", "created_at": "..." }
        ]

Errors: 500 server error.

Friendships

Friendships are one-way. Adding someone lets them see your friends-only posts.

POST /friendships

Requires auth. Adds a user as a friend of the logged-in user.

Body:

{ "friend_id": 2 }

Returns 201:

{
        "message": "Friend added successfully",
        "result": { "user_id": 1, "friend_id": 2, ... }
        }

Errors: 500 server error, including when the friendship already exists.

GET /friendships

Requires auth. Returns everyone the logged-in user has added.

Body: none

Returns 200:

[
        { "user_id": 1, "friend_id": 2, ... }
        ]

Errors: 500 server error.

DELETE /friendships/:id

Requires auth. Removes a friend. :id is the friend's user ID.

Body: none

Returns 200:

{
        "message": "Friend removed successfully",
        "result": { "user_id": 1, "friend_id": 2, ... }
        }

Errors: 404 the logged-in user hasn't added this user, 500 server error.

Any other route returns 404 with { "error": "Route not found" }.

Every error response except the 401s from auth-protected routes has the shape { "error": "message" }.
